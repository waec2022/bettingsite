How a Bet9ja booking code works

After we publish a prediction or accumulator, each one can carry its own Bet9ja booking code. On Bet9ja's booking page, enter the code to instantly load every selection in that slip — the matches, markets and odds are filled in automatically, and you just confirm your stake.

Booking code vs. promo code

These are two different things, and we keep them separate so you're never confused: a booking code identifies one specific bet slip (today's accumulator, for example). A promo code is a one-time signup code used when creating a new Bet9ja account. Using the wrong one in the wrong place won't load your bet correctly.
